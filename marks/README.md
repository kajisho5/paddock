# 目印画像（演者フォルダに入れる 00_受付済.jpg など）

PADDOCK SCOUT・SADDLE・GATE が名前で読み取る目印に合わせた画像の一式です（`目印画像/` に 30 枚、600×600 の JPG）。

- 使い方：受付で、演者フォルダにそのままコピーします。PADDOCK SADDLE なら［設定］→「受付」の「目印画像のフォルダ」にこのフォルダを指定すると、受付パネルから付け外しできます
- 白地に、役割の色の丸と絵（PC・動画・マイク・旗など）、下に文字。エクスプローラーの縮小表示でも見分けやすいように
- 色は役割ごと：青＝受付、緑＝会場で取得、紫＝会場で受け取る、赤＝注意、オレンジ＝オペが対応、灰＝取り下げ・お知らせ、濃紺＝発表済み
- 「読んでください」「連絡」などの中身のあるお知らせは、画像ではなく .txt（例：読んでください.txt）に書いてください。GATE・SCOUT は目印として赤く出し、中身をメモとして表示します
- 名前の先頭の番号は並び順のためのものです（番号を変えても、番号なしでも目印として読めます）
- 作り直す・増やす：`python3 marks/make_marks.py`（`MARKS` に名前と文字を足す。目印として読めない名前ならエラーで止まります）
