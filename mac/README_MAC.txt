PADDOCK（Mac 版）

1. この中のアプリ（.app）を「アプリケーション」フォルダにドラッグします。
2. アプリケーションフォルダからダブルクリックで起動します。画面（Chrome があれば専用ウィンドウ、無ければ既定のブラウザ）が開きます。
3. 動いている間は、画面上のメニューバーにアイコンが出ます。アイコンから［画面を開く］［終了］。
   画面のウィンドウを閉じても動いています（PADDOCK SCOUT は画面を閉じると終了します）。

・設定と記録は ~/ライブラリ/Application Support/<アプリ名> に保存されます。
・PADDOCK GATE の「スライドショーで開く」は PowerPoint（無ければ Keynote）に頼みます。初回は
  「PADDOCK GATE が PowerPoint を制御しようとしています」と出るので［OK］を押してください。
  断ってしまったときは システム設定 → プライバシーとセキュリティ → オートメーション で許可できます。
・新しい版に入れ替えるときは、メニューバーのアイコンの［終了］で前の版を終了してから起動してください。
・ネットワーク共有のワンボタン設定・ファイアウォールの許可ボタンは Windows だけの機能です。
