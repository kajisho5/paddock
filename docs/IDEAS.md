## GATE：PowerPoint の固まりを見張って、バックアップPCで同じスライドを出す（2026-10-23）

状態：メモだけ。まだ実装しない。

### やりたいこと
メインPCの PowerPoint が固まったら、バックアップPCで同じスライドをスライドショーにする。

### できること（技術的に）
- **固まりの判定**：メインPCの GATE が、PowerPoint が応答しているかを数秒ごとに確認する。Windows 標準の「応答なし」判定（Process.Responding や IsHungAppWindow）を使う。
- **スライドショーの状態と枚数**：COM で読む。
  - SlideShowWindows(1).View.State：表示中・黒画面・終了など
  - View.CurrentShowPosition：いま何枚目か
- **バックアップPCの待機**：既存の Pair 連携（UDP・HMAC 署名）で枚数を送る。バックアップPCは、同じ演者のスライドを同じ枚数で開いて待つ（GotoSlide）。
- **メインPCごと固まった場合**：メインPCの GATE も止まる。バックアップPCは、Pair の応答が途切れたことで検知する。

### 問題になる点
- **映像の切り替えはスイッチャー**：バックアップPCでスライドショーを出しても、切り替えない限り客席には映らない。Companion で操作できるスイッチャーなら自動化もできるが、次の誤判定があるので自動切り替えは危険。
- **誤判定**：
  - 重い動画の読み込みなどで、PowerPoint が正常でも数秒「応答なし」になることがある。
  - LAN ケーブルが抜けただけでも「メインPCが固まった」ように見える。
  - 自動で切り替えると、発表中に画面が飛ぶ（会場側の事故になる）。
- **合わせられるのは枚数まで**：スライド内のアニメーションの途中や、動画の再生位置は合わせられない。
- **スライドショーを抜けた状態（待機）**：普通の操作でも起きるので、切り替えの合図には使えない。

### やるならこの形
1. メインPCで PowerPoint を監視し、固まったら GATE とバックアップPCの両方に大きく警告する。
2. バックアップPCは、常に同じスライドを同じ枚数で準備しておく。
3. 切り替えは人がスイッチャーで行う（または Stream Deck のボタン1つ）。
4. 実機の Windows と PowerPoint で、固まったときの動きを試してから入れる。
