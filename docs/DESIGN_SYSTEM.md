# PADDOCK デザインシステム

PADDOCK SCOUT（監視）・SADDLE（受付）・GATE（会場PC）の画面は、すべてこの決まりで作る。
見本ページ：`cd ui && npm run design` → `ui/dist-design/design.html` をブラウザで開く（アプリには含めない）。

## 層の構成

| 層 | ファイル | 役割 |
|---|---|---|
| トークン | `ui/src/design/tokens.css` | 色・文字・角丸・影・動きの値。テーマ（light / dark）ごとに定義 |
| Tailwind | `ui/src/design/tailwind.css` | トークンを Tailwind のクラス名にする（`bg-card` `text-ok-fg` `rounded-card` `shadow-elev-2` `animate-fade-up` など）。preflight は使わない |
| 部品 | `ui/src/design/ui.tsx` | `Segmented`（タブ）・`Bar`（進捗）・`EmptyState`・`StatusDot`・`Chip` |
| 画面の基本スタイル | `ui/src/styles.css` | 既存の画面（一覧・ボード・ダイアログなど）のクラス |
| 動き | `ui/src/design/motion.css` | すべてのアニメーション。最後に読み込む |

読み込み順（`main.tsx`）：tailwind → tokens → styles → motion。

## テーマ

- **light**：SCOUT・SADDLE（明るい本部・受付デスク）
- **dark**：GATE（会場の発表PC。暗い会場で目立たず、状態ははっきり）。アクセントの緑は少し深い芝の緑
- テーマはアプリの種類で決まる（`data-theme`）。利用者が切り替える設定は作らない

## 色（意味で使う）

| 名前 | 意味 | 使う所 |
|---|---|---|
| `ok` | 受付済み・正常・監視中 | 状態の点、受付済みのチップ、主要な実行ボタン（GATE のスライドショー） |
| `got` | 会場取得・未読 | 会場取得済み、未読の点 |
| `warn` | 注意・コピー中・差し替え | コピー中、PC持込、更新した行の光 |
| `bad` | 未着・つながらない・エラー | 未受付、接続できない、削除 |
| `vio` | 会場直・差し替え回数 | |
| `info` | COI など情報 | |

- それぞれ `-bg`（薄い背景）と `-fg`（文字）がある。例：`bg-warn-bg text-warn-fg`
- 色の値（#xxxxxx）を画面のコードに直接書かない
- 色だけで状態を伝えない（必ず文字かアイコンを添える）

## 文字

- 本文 14px、補助 12.5px、最小 11px。見出し 19px（ダイアログ）、演者名 30px
- ウェイトは 400〜700。細いウェイト（300 以下）は使わない
- パス・時刻・数値は等幅（`font-mono`）

## 角丸・影

`--r-sm 7` / `--r-md 9`（ボタン・入力）/ `--r 12`（カード）/ `--r2 16`（パネル）/ `--r-xl 18`（ダイアログ）/ `--r-full`
影：`elev-1`（パネル）・`elev-2`（ポップオーバー・トースト）・`elev-3`（ダイアログ）

## 動き

| トークン | 値 | 使う所 |
|---|---|---|
| `--dur-1` | 120ms | 押したときの縮み・ホバー |
| `--dur-2` | 200ms | トースト・ポップオーバー・タブの中身・選んだ演者の中身 |
| `--dur-3` | 320ms | ダイアログ・ドロワー・ログの出入り・進捗バー・タブの下地の移動 |
| `--dur-4` | 2400ms | 更新した行が光って消えるまで |

カーブ：入る＝`--ease-out`、出る＝`--ease-in`、位置の移動＝`--ease-inout`、少し弾む＝`--ease-spring`（トーストなど小さいものだけ）。

決まり：
1. **動かすのは `transform` と `opacity` だけ**。幅・高さ・位置・背景色はアニメーションしない（発表PCでスライドショー中でもカクつかないように）。進捗バーも幅ではなく `scaleX` で動かす（`Bar` 部品）
2. **ずっと動き続けるものは最小限**：監視中の点の波紋、コピー中の演者の光、読み込み中のバーだけ
3. **OS の「アニメーションを減らす」がオンなら止める**（`prefers-reduced-motion`）
4. 情報を動きだけで伝えない（光った行には「更新」のチップも付く）

## 部品

- `Segmented`：表示の切り替え・設定のタブ。選んだ項目の下地が移動する
- `Bar`：進捗（0〜100）
- `EmptyState`：何も無いときの表示（既定のアイコンは蹄鉄）
- `StatusDot`：on（正常）/ busy（コピー中など）/ off（つながらない）
- `Chip`：小さな状態ラベル（tone = ok / got / warn / bad / vio / info / none）

新しい画面は、まずこの部品と Tailwind のトークン名で組む。足りない部品はここに追加してから使う。
